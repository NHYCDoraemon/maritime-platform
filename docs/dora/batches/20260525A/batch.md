# Batch Summary

本批任务用于落地统一 `platform-gateway-starter`。交付目标是把 gateway 中通用、独立、可复用的安全与横向逻辑沉淀为平台 starter，让新项目只通过依赖和配置即可获得标准 gateway 能力。

本批任务不做 `todo-center`、`iam-center` 或 `process-engine` 的迁移，只建设平台基础能力。
